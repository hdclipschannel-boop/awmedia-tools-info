AW Media Dashboard - Privacy Policy

Last updated 4 November 2026.

Who uses it

AW Media Dashboard is a private tool used only by its owner, on the owner's own computer. It has no other users and is not offered to the public.

What Google data it uses

With the owner's permission, the tool uses the Google Sheets API to add rows to a spreadsheet the owner already has access to. It reads that spreadsheet only to find the next empty row and to avoid adding the same entry twice.

What it stores

The sign-in permission Google issues is stored only on the owner's computer. The tool keeps no copy of any spreadsheet and has no server of its own.

Sharing

No data is sold, shared with, or sent to anyone. Nothing is used for advertising.

Removing access

The permission can be removed at any time in the Google Account under Security → Third-party apps & services.
